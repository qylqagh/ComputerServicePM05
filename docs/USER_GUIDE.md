# Руководство пользователя

## 1. Вход в систему

Запустите ComputerServicePM05.exe. В форме «Авторизация» введите логин и пароль и нажмите «Войти» или клавишу Enter. При неверных данных система выведет сообщение об ошибке и очистит попытку входа.

Тестовые учетные записи: admin / admin (администратор), user / user (пользователь).

## 2. Главное окно

Слева расположено меню разделов и сведения о текущем пользователе. Справа — сводка: количество клиентов, устройств, активных заявок, запчастей на складе и список последних заявок. Кнопка «Выйти» завершает сеанс и возвращает к форме авторизации.

## 3. Раздел «Клиенты»

Таблица клиентов с поиском по ФИО и телефону. Кнопка «Добавить» открывает карточку нового клиента: ФИО и телефон обязательны, email необязателен и проверяется на формат. Кнопка «Изменить» открывает карточку выбранного клиента. Кнопка «Удалить» доступна только администратору и запрещена, если по клиенту есть заявки.

## 4. Раздел «Устройства»

Таблица устройств с поиском по производителю, модели и серийному номеру. В карточке категория выбирается из выпадающего списка. Удаление доступно администратору и запрещено для устройств с заявками.

## 5. Раздел «Заявки на ремонт»

Таблица заявок с фильтром по статусу и поиском. Кнопка «Добавить» открывает карточку: клиент, устройство, статус, ответственный сотрудник, описание неисправности, стоимость работ, примечание. Двойной щелчок по строке открывает карточку заявки.

В карточке существующей заявки доступна таблица списанных запчастей: «Списать запчасть» открывает диалог выбора запчасти и количества с контролем остатка склада, «Вернуть запчасть» возвращает количество на склад. Итоговая стоимость пересчитывается автоматически как сумма работ и запчастей. При переводе заявки в статус «Выдано» или «Отменено» автоматически проставляется дата закрытия.

Удаление заявки доступно администратору; списанные запчасти при этом возвращаются на склад.

## 6. Раздел «Запчасти»

Таблица склада с поиском по артикулу и названию. Пользователь видит склад только на просмотр. Администратор может добавлять, изменять и удалять запчасти; артикул проверяется на уникальность, удаление запрещено для запчастей, списанных в заявки.

## 7. Раздел «Пользователи» (только администратор)

Таблица учетных записей с поиском. Кнопка «Добавить» открывает карточку: логин проверяется на уникальность, пароль минимум 4 символа, роль выбирается из списка. Кнопка «Изменить» правит учетную запись. Кнопка «Статус» отключает или активирует учетную запись; отключенный пользователь не сможет войти. Свою учетную запись отключить нельзя.

## 8. Типовые сообщения системы

- «Вы ввели неверный логин или пароль...» — ошибка входа.
- «Проверка данных» — незаполненные или некорректные поля карточек.
- «Подтверждение удаления» — запрос подтверждения необратимой операции.
- «Операция запрещена» — действие нарушает целостность данных или права доступа.
- «Ошибка базы данных» — сбой обращения к файлу базы; проверьте, что файл базы не удален и не занят другой программой.
