# ComputerServicePM05 — ИС «Сервисный центр компьютерной компании»

Десктопная информационная система для учета клиентов, техники, заявок на ремонт и склада запчастей сервисного центра компьютерной компании. Учебный проект по ПМ.05 «Проектирование и разработка информационных систем».

## Стек

- C# 12, .NET 8, Windows Forms
- SQLite, драйвер Microsoft.Data.Sqlite
- Visual Studio 2022/2026, Windows 11 x64

## Возможности

- Авторизация по логину и паролю, две роли: Администратор и Пользователь
- Сводка на главной: счетчики и последние заявки
- Клиенты: поиск, добавление, изменение, удаление (админ)
- Устройства: справочник категорий, поиск, карточки
- Заявки на ремонт: фильтр по статусу, поиск, карточка заявки, ответственный сотрудник, автоматический расчет стоимости
- Склад запчастей: списание в заявку с контролем остатка и транзакционным возвратом при удалении заявки
- Пользователи (админ): добавление с проверкой дубликата логина, отключение и активация учетных записей
- Валидация ввода, подтверждения удалений, информативные сообщения об ошибках, обработка сбоев БД без аварийного завершения
